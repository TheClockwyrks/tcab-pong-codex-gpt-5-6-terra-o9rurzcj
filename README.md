# Carom

Carom is a fast top-down paddle duel. Curve a rally with paddle motion, bank it through the central obstacles, and be the first player to win by two.

## Run it

```sh
npm ci
npm run dev
```

Build the self-contained production site with `npm run build`; it is written to `dist/` and can be served by any static web server.

## Controls

- Left paddle: `W` / `S`
- Right paddle: arrow keys (or either set in Solo)
- Select: `Enter` or `Space`
- Pause: `P` or `Escape`
- Sound: `M`

In Solo, play the left paddle against the reactive AI. In Versus, share the keyboard for a local duel. Move your paddle while making contact to add spin and send the ball on a satisfying curve.
